# Official competition kit copies

These four files are copies of the organiser material supplied to the team:

- `Technical Phase Brief.pdf` — submission rules, deadline and judging criteria.
- `Problem Statement and Judging Guide.docx` — problem and judging context.
- `Pitch Deck Template.pdf` — reference rendering of the pitch template.
- `Pitch Deck Editable.pptx` — editable deck supplied with the local kit.

The official **synthetic** starter dataset is tracked separately under [`data/raw/`](../data/raw/README.md), including all 11 CSVs and its dictionary. The 38 MB `Hackathon Starter Dataset.zip` is deliberately not duplicated here: all 17 files in that archive were compared with `data/raw/` and match after Git line-ending normalization. The archive lists `blood_system.sqlite` in its README but does not contain that database. A local SQLite store must be derived from the CSVs.

These files are reference materials, not pre-written application code or benchmark outputs. If an organiser's live document changes, verify it before submission; copies here reflect the kit found in the team's local workspace on 10 November 2026.
