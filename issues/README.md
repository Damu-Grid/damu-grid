# issues/

Local drafts of GitHub issues. **Do not open these on GitHub until a teammate explicitly publishes them.** Agents must not create remote issues, push, or assign people on github.com from this folder alone.

- Human-readable list and hours table: `ISSUES.md`
- Machine-readable: `issues.json`

If an issue is opened remotely, keep the local id and the GitHub number in sync by editing these files by hand.
