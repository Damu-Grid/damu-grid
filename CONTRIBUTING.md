# Contributing (Team Damu Grid)

This repository is the team's 24-hour hackathon build. There is no team lead. Read `AGENTS.md`, `docs/ROLES.md` and `docs/GITHUB_RULES.md` before you write code.

## Before you start

1. Confirm your ownership area in `docs/ROLES.md` and pick an issue from `issues/ISSUES.md`.
2. Work on a branch. Open a pull request. Prefer small, frequent commits with a conventional message.
3. Do not edit `data/raw/`. Do not commit `.env` or secrets.
4. Write tests for workflow, eligibility and evaluation changes.
5. If an AI coding tool writes or substantially edits code, the human still has to be able to explain it, and the tool must be listed in the root README before submission.

## Reviews

Anyone can review. For a change in someone else's ownership area, ask that teammate to look if they are online. Do not block a fix that keeps the prototype running.

## Issues

The planned issue list lives in `issues/` until a teammate publishes it to GitHub by hand. Agents must not create GitHub issues or push unless a human has approved that specific action.
